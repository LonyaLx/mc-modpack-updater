# MC 整合包更新器

Minecraft 整合包增量更新工具，支持 Forge / NeoForge / Fabric 全版本。

## 功能特性

- ✅ **一键更新** — 选两个文件夹，点一下就完事
- ✅ **目录自动识别** — 支持各种启动器 / 各种压缩包结构，选错层级也会自动纠正
- ✅ **增量更新** — 只更新有变化的文件，速度快省流量
- ✅ **配置保留** — 键位、JEI设置等个人配置自动保留
- ✅ **用户数据保护** — 存档、截图、小地图、自己放的资源包/光影、服务端世界等全程不动
- ✅ **自加文件保护** — 更新过一次后，你手动添加的模组不会被当成"旧文件"删掉
- ✅ **一键回退** — 出问题随时撤回，支持多选批量回退
- ✅ **备份管理** — 更新后自动只保留最近 3 份备份，可一键清理，不再无限占空间
- ✅ **磁盘预检** — 备份和写入前先估算所需空间，空间不足提前提示，不会留下「半更新」状态
- ✅ **模拟更新** — 预览更新效果，只读不修改，放心确认
- ✅ **NeoForge 检测** — 自动检测加载器版本，提前预警
- ✅ **Fabric 检测** — 支持 Fabric Loader 版本检测与警告
- ✅ **游戏运行检测** — 更新前检测游戏是否在运行，防止文件损坏
- ✅ **支持压缩包** — 直接选 .zip / .mrpack，不用手动解压
- ✅ **中文压缩包兼容** — 能正确处理 WinRAR/好压 等用 GBK 存文件名的中文整合包
- ✅ **Modrinth 支持** — 直接选 `.mrpack`（或含清单的 zip），自动读取 `modrinth.index.json`
  并**并发下载**清单里声明的全部模组（带 SHA1 校验、本地缓存、失败重试），
  再合并 `overrides` 与 `client-overrides`（后者优先，符合官方规范）
- ✅ **不重复下载** — 更新 `.mrpack` 前先拿旧整合包对照：里面已经有一模一样的模组
  就直接复用（硬链接，秒完成、不占额外空间），只下载真正新增/升级的那几个
- ✅ **临时文件同盘** — 解压 / 下载的临时文件放在整合包目录的 `.updater/_tmp`，
  不会突然占满系统盘，程序关闭时自动清理
- ✅ **安全保护** — 误删检测 + 游戏运行提醒 + 路径穿越防护，多重保护
- ✅ **AE 风格界面** — 亮色科技风，清爽好用
- ✅ **绿色免安装** — 单EXE文件，无需Python环境，双击即用

## 支持的目录结构（别人的整合包也能用）

程序会自动找到整合包真正的根目录，下面这些「选法」都认得：

| 你选的目录 | 程序会自动进入 |
|------|------|
| 整合包文件夹（里面有 `mods/`） | 原地使用 |
| `.minecraft` 根目录（PCL / HMCL / BakaXL 版本隔离） | `versions/<整合包实例>/` |
| PrismLauncher / MultiMC 实例目录（`instances/<名>/`） | 里面的 `.minecraft/` |
| Modrinth App / CurseForge 客户端实例 | 原地使用 |
| 解压出来的压缩包（多套一层、带 README、带 `__MACOSX`） | 自动一层层钻到整合包根 |
| CurseForge 官方 zip（`manifest.json` + `overrides/`） | `overrides/` |
| Modrinth 整合包（`.mrpack`） | 自动下载清单模组后合并 |

> 选错层级、或选到不含 `mods/` 的目录时，程序会给出明确提示，不会盲目乱删。

## 哪些东西永远不会被改

| 类别 | 内容 |
|------|------|
| 用户数据（不新增、不修改、不删除） | `saves/`、`screenshots/`、`replay_recordings/`、`backups/`、`journeymap/`、`xaero/`、`servers.dat` |
| 服务端 | `world/`、`world_nether/`、`world_the_end/`、`server.properties`、`whitelist.json`、`ops.json`、`eula.txt` |
| 自己放的东西（已有内容不被覆盖，也不会删） | `resourcepacks/`、`shaderpacks/`、`schematics/`、被禁用的模组 `*.disabled` |
| 手动添加的文件（更新过一次后） | 不在上次整合包标准清单里的文件，默认保留 |
| 可选保留 | 勾选「保留配置文件」后，`config/`、`options.txt` 等也不被覆盖 |

## 支持的整合包格式

| 格式 | 说明 |
|------|------|
| 文件夹 | 指向整合包根目录（含 `mods/`）或 `.minecraft` 根目录，自动定位实例 |
| `.zip` | 普通整合包压缩包，自动解压；自动识别 CurseForge `overrides` 外壳 |
| `.mrpack` | Modrinth 整合包，自动下载清单模组（**需要联网**） |

## 使用方法

1. 双击运行 `MC整合包更新器_v1.0.exe`
2. 选择本地旧整合包目录
3. 选择新版本整合包（支持文件夹 / `.zip` / `.mrpack`）
4. 点击「检测差异」→ 建议先「模拟更新」预览 → 确认后点「立即更新」

> Modrinth 整合包的模组不在压缩包里，程序会自动联网下载（首次可能几百 MB），
> 下载进度会实时显示；已下载文件会缓存，重复检测不会重复下载。

- Windows 7 / 8 / 10 / 11
- 无需安装 Python

## 开发者：兼容性自检

改完代码后可以跑一遍自带的自检脚本，确认各种整合包结构 / 用户数据保护都没被改坏：

```bash
python 自检-兼容性.py
```

它会把 PrismLauncher、MultiMC、HMCL/PCL、Modrinth App、CurseForge、各种压缩包层级、
GBK 中文压缩包、服务端整合包、路径穿越等场景全部模拟一遍，全部通过才打印「全部通过」。
仅依赖 Python 标准库，不需要联网。
